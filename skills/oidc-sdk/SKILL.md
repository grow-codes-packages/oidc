# OIDC SDK (Grow Codes)

One API for OIDC in five languages (categories: auth). Pick the package for the
project's language, configure it from the environment, and handle errors by their canonical code.

## 1. Add the package

| Language | Command | Import |
| - | - | - |
| TypeScript | `npm install @grow-codes/oidc` | `import { OidcClient } from "@grow-codes/oidc"` |
| Rust | `cargo add grow-oidc` (add `tokio` with `macros,rt-multi-thread`) | `use grow_oidc::OidcClient;` |
| Go | `go get github.com/grow-codes-packages/oidc/go` | `oidc "github.com/grow-codes-packages/oidc/go"` |
| Python | `pip install grow-oidc` (or `uv add grow-oidc`) | `from grow_oidc import OidcClient` |
| Java | Maven `codes.grow.packages:oidc` (Gradle `implementation("codes.grow.packages:oidc:<version>")`) | `import codes.grow.packages.oidc.OidcClient;` |

Check the latest version in the README badges before pinning one.

## 2. Configure

Prefer environment configuration so no credential is written into code:

```sh
export GROW_OIDC_URL=https://oidc.example.internal
export GROW_OIDC_TOKEN=...            # from your secret store, never committed
```

Precedence: explicit config value > `GROW_OIDC_*` > vendor variables (`GROW_AUTH_ISSUER`, `GROW_AUTH_AUDIENCE`, `GROW_AUTH_JWKS_URL`, `GROW_AUTH_ROLES_CLAIM`, `GROW_AUTH_CLIENT_ID`, `GROW_OIDC_*`) > default.
Other variables: `…_CONNECT_TIMEOUT`, `…_REQUEST_TIMEOUT`, `…_TOTAL_TIMEOUT` (`10s`, `1500`),
`…_MAX_RETRIES`, `…_CA_CERT`, `…_CLIENT_CERT`, `…_CLIENT_KEY`, `…_PROXY`. Environment proxies
(`HTTPS_PROXY`) are ignored unless `proxy` is set.

## 3. Use

Create one client per process and close it on shutdown (TypeScript `await client.close()`, Rust
`client.close().await`, Go `defer client.Close()`, Python `with …`/`close()`, Java
try-with-resources).

- `health()` never throws for an unhealthy service; check `healthy`.
- `ping()` verifies credentials (`AUTHENTICATION` error when they are wrong).
- All I/O is retried with jitter on 429/502/503/504 and connection errors; only idempotent calls
  are retried on 500.
- Errors carry `code` (`CONFIG`, `AUTHENTICATION`, `PERMISSION_DENIED`, `NOT_FOUND`, `CONFLICT`,
  `RATE_LIMITED`, `VALIDATION`, `UNAVAILABLE`, `TIMEOUT`, `UNSUPPORTED`, `CANCELLED`), `retryable`,
  `httpStatus` and `requestId`. Branch on the code, not on the message text. Go:
  `errors.Is(err, oidc.ErrNotFound)`.

### Verify access tokens (the main use)

Configure `GROW_AUTH_ISSUER` (must equal the token `iss`), `GROW_AUTH_AUDIENCE` (default
`GROW_AUTH_CLIENT_ID`), optional `GROW_AUTH_JWKS_URL`, `GROW_AUTH_ROLES_CLAIM` (default `roles`).

- TypeScript: `const v = Verifier.fromEnv(); app.use(expressAuth(v)); app.get("/admin", requireRoles("admin"), h)`;
  NestJS `app.useGlobalGuards(new NestAuthGuard(v), new RolesGuard())` + `@Public()` / `@Roles("admin")`.
- Go: `v, _ := oidc.FromEnv(ctx); mux.Handle("/api/", v.Middleware(oidc.RequireRoles("admin")(h)))`; `oidc.UserFrom(ctx)`.
- Python: `Depends(require_user(roles=["admin"]))` (FastAPI), `OidcMiddleware` (ASGI), `DjangoOidcMiddleware`.
- Java: `new OidcFilter(Verifier.fromEnv())` + `new RequireRolesFilter("admin")`.
- Rust: `.layer(OidcLayer::new(Verifier::from_env()?))` + `RequireRolesLayer::new(["admin"])` (feature `tower`).

Adapters answer 401 / 403 / 503 without saying why. Full API: `AGENTS.md` inside each package and
`docs/verification.md`. Test with the fake IdP (`FakeIdp`, `oidctest`, `FakeIdP`).

## 4. Test code that uses the SDK

Use the in-memory fakes from the testing module instead of a real OIDC in unit tests:
TypeScript `@grow-codes/oidc/testing`, Rust feature `testing`, Go package `testkit`, Python
`grow_oidc.testing`, Java `codes.grow.packages.oidc.testing`.

## 5. Work on this repository

Read `AGENTS.md` first. Short version: the five languages keep the same API; files with the
`Generated by sdk-kit` header are changed in sdk-kit, not here; `make lint coverage` must pass
(≥ 90 % lines and branches); `make test-docker LANGS="<lang>"` runs the integration suite against
`casbin/casdoor:v4.27.1`.
